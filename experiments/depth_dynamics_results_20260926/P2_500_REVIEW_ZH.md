# P2：0–500 步独立证据复核

日期：2026-09-26。复核范围：`20260926_stage1_calibrated_seed0/summary500` 五张汇总表、`diagnostics/paired_state500.json`，随后补充到本地的 `per_image_through500.csv` / `per_image_through500_sources.json`，以及共用米制色标的 `paired_depth_step_000500.png`。本报告不改训练代码，不包含尚未完成的 P3/1000/2000 步结果。

## 核心判断

同一起点、同一抽样顺序的这次 seed-0 配对中，D1（all）到 500 步发生了明显的几何退化：固定验证帧 MAE 为 **34.806 mm**，D0（none）为 **4.001 mm**，相差 **8.70 倍**。D1 的平均局部斜率为 **−0.7135**、局部对比度比为 **2.3794**，并伴有 **+31.632 mm** 的深度偏差。逐图证据进一步确认 D1 的 **32/32 验证帧局部斜率为负**，并且各帧 MAE 均高于配对 D0。共用色标的固定图像也显示前景物体明显的正深度误差和形状反向变化；D0 图像保持接近 GT。

**这不是当前预设判据下的恒定深度塌缩。** 两臂各检查点的平坦图像比例均为 0，500 步初始平坦/首次阈值/确认事件均未触发。D1 前景 std ratio 为 **1.37767**，而汇总表中的全 GT-valid 域逐图 std ratio 平均为 **1.00556**；两者掩码不同，不得互换。整体标准差接近 1 并不保证物体几何正确。现有结果支持把后续 E-only/Q-only 的目标定义为“重现或缓解几何退化表型”，不能把它改写成已重现恒定塌缩。

## 配对依据与统计口径

- 实验主版本为 `aa4ffd20ee52f0a60f776c1c3b90d048ef7fa216`。500 步两臂都成功更新 500 次、见过 500 张训练图；验证固定集均为 32 帧，训练探针为 16 帧。用户指定的 `test_seen` 在此作为验证集，不是未使用的最终测试集。
- `paired_state500.json` 确认 500 步 RNG、loader、module.training、is_training 完全匹配，记录的更新步与样本索引也匹配。这支持配对解释；它不声称两臂参数/优化器应相等，也不把已知 CUDA 反传数值噪声说成位级确定性。
- 补充逐图 CSV 共 1344 行，无 arm/step/split/mode/frame/index 重复；初始两臂逐图指标相同。验证的 32 帧来自 30 个 scene，不能把同 scene 多帧当作完全独立重复，也没有跨 seed 置信区间。局部斜率是固定同实例像素对的 `Σ(Δpred·ΔGT)/Σ(ΔGT²)`，先逐图计算后平均；局部对比度是对应差分 RMS 比。逐图表能确认帧级负斜率比例，但没有实例级分解，因此仍不能推出每个物体或每对像素都反转。
- 本报告筛选 `D0/D1 + eval + validation_test_seen`；不把附带的 P0 行当成额外训练检查点。训练/验证的平坦判据分别有 16/32 张合格图；表内 MAE、std 和覆盖量均为逐帧平均，不是把像素或查询跨帧混池后的量。

D1 到 50 步已与 D0 分离；100 步明显恶化，200–300 步部分恢复，500 步再次大幅变坏。因此不宜用“500 步首次异常”或“单调失稳”描述。固定探针仅定位严重变化发生在 400 与 500 步之间，不能给出确切发生步。500 步训练探针同样出现 MAE **42.339 mm**、bias **+39.357 mm**、斜率 **−0.5748** 和对比度比 **2.0888**，所以现象不只是验证帧误差变大。D0 验证局部斜率由初始 0.6370 到 0.6217，表明它较稳定，但也不能称为完美几何。

## 补充逐图证据：广泛前景失真，而非少数离群帧

逐图表复核 D1@500：局部斜率范围 **−1.28557 至 −0.35543**，中位数 **−0.69884**；全部 32 帧的局部相关系数也为负。有效域 MAE 中位数 **34.161 mm**，P10/P90 为 **23.922/48.573 mm**，每帧都高于 D0。D1 的负斜率帧数依次为：0/50 步 **0/32**，100 步 **7/32**，200/300/400 步 **0/32**，500 步 **32/32**；D0 所有这些检查点均为 **0/32**。这确认中间发生过恢复，500 步的平均反转并非少数离群帧造成。

| 500 步逐帧指标均值 | D0 | D1 |
| --- | --- | --- |
| 前景 MAE/mm | 7.333 | 91.972 |
| 背景 MAE/mm | 2.397 | 7.008 |
| 前景 bias/mm | +0.457 | +91.067 |
| 前景 std ratio | 0.98264 | 1.37767 |

全有效域 MAE 34.806 mm 明显低于前景 MAE 91.972 mm，表明背景像素会稀释物体上的失真。前景 bias 接近前景 MAE，支持前景整体偏向较大 z，同时局部负斜率说明不只是加了均匀偏移；两个现象应并列报告。逐帧 raw sigmoid 极端占比（sigmoid<0.01 或 >0.99）为 0，对“整体 sigmoid 饱和导致失真”的解释不提供支持。

| --- | --- | --- | --- |
| 每帧 CDF 正样本数 | 5950.4062 | 6351.1562 | 45.5938 |
| 每帧 CDF valid 数 | 28357.5000 | 29356.5000 | 855.0000 |
| point-valid 比例 | 0.6483 | 0.6711 | 0.0196 |
| view-valid 比例 | 0.8882 | 0.8927 | 0.9077 |
| NN 平均距离（mm） | 5.8501 | 5.5896 | 67.9441 |
| 中心 z 误差（mm） | 7.4133 | 7.2386 | 112.8475 |
| axis-radius 上界外比例 | 0.7807 | 0.7709 | 0.4276 |

D1@500 的 CDF 正样本仅约为初始的 **0.77%**，CDF valid 数约为初始的 **3.02%**。point-valid 降至 **1.96%**；与此同时 view-valid 仍为 **90.77%**。这说明查询与标签支持严重退化，却不是所有抓取监督同时消失。NN 距离和中心 z 误差来自查询/匹配范围，不能与全 GT-valid 像素 MAE 当成同一个采样域直接相减。

在固定验证探针中，seed clamp/fallback 始终为 0；有效 support residual 越界比例几乎为 0（仅 D1@200 上界外约 2.27e−7）。全有效域 sigmoid 导数均值保持约 0.242–0.246，接近其上限 0.25，而非整体进入饱和。axis-radius 上界外比例初始即约 78.1%，D1@500 反而降为 42.8%；不能把它的存在本身当作突然失稳的证据。以上只排除这些**汇总量**呈现的大规模新饱和/硬边界失效，不能排除局部像素、其他连续非光滑分支或未汇总状态。

身份切换表另有重要限制：D0@500 和 D1@500 的 aligned-slot query identity 切换率分别为 99.875% 与 99.966%。这首先表明对齐槽位多数不再代表同一查询，不能据约 100% 的槽位 NN 变化直接宣称物理查询匹配不稳定。仅同槽位 token/view 身份仍相同的子集，D0/D1 位移分别为 3.524/53.725 mm，NN 切换为 47.2%/100%；但此统计只有 **16/8 帧**有观测，汇总 CSV 没保留该子集查询数。`/ observed` 是有观测的帧数，不是查询数；这些值只能作带选择性的佐证。

500 步这一个训练 batch 中 D1 的 CDF/width loss 为 0，与监督支持减少一致；固定验证集仍有少量有效/正样本，且 view loss 非零，故不能外推成所有帧所有抓取梯度均为零。D1@350 的总梯度范数曾为 33.135，但裁剪后深度参数实际更新范数只有 0.08224；@500 也只是 D0 更新范数的约 **1.38 倍**。不能由裁剪前峰值直接推出某一步参数爆炸，更不能把 AdamW 更新等同于当前梯度乘学习率。

固定训练探针 index=0 的加权深度参数梯度范数如下：D1@200，depth/view/CDF/width 为 **4.1504/2.4087/1.6884/1.4271**；@400 为 **4.5468/4.5804/2.4770/0.8018**。D0 的所有抓取项对深度参数均为 unused/None。它说明 D1 的 view 梯度在该帧已可与 depth 同量级，不能据范数判定梯度方向、冲突比例或主导实际参数位移；也不能把各 loss 范数相加当成总梯度。

路由干预还经全局裁剪影响其他参数更新：首次前向 loss 相同，但 D0/D1 裁剪系数已为 **0.447081/0.461929**。后续模型、查询、匹配与 AdamW 状态会一同演化。因此 D0/D1 识别的是这一训练配置下整个路由干预的轨迹差异；不是在抓取头轨迹固定时，孤立加上某个深度梯度的效果。

## P3 与后续解释建议

1. **E-only（gse）和 Q-only（seed_xyz）是合理的定向对照。** P1 的路由连通性与加权梯度提供候选依据，当前 P2 给出值得解释的表型。两臂从与 D0/D1 相同的 stage-1 初始化、同 seed/顺序/学习率/预算出发；已启动的 500 步配对符合此目的。保持所有深度、局部几何和覆盖指标，不能只看总 loss 或 std ratio。
2. **先做描述性比较，勿倒填旧事件标签。** 500 步主要终点可并列报告 MAE、bias、固定同实例局部斜率/对比度、前景 std、CDF/point-valid 覆盖与共用色标图。若要新增“几何退化事件”阈值，应明确它由本次观察后提出，并在读取 P3 结果前固定；旧恒定塌缩事件字段保留原意。已补取的逐图结果确认 32/32 帧级负斜率；P3 同样应报告该分布，以区分少数失败与多数帧一致失真。
3. **E-only 或 Q-only 若重现，结论限定为本初始化、seed、预算和配置下该干预可以产生相似表型。** 不能据一条轨迹宣称该路径普遍充分，更不能说明它是 all 路径中必要的唯一原因。单路未重现也不能否定该路参与失稳；全路径可能存在交互、反馈或时间尺度差异。
4. **解释 Q-only 时保留 C 路的抵消可能。** 既有 P1 原生方向导数提示 Q/C 常有反向抵消；Q-only 的效果不等于 all 中 Q 的可加贡献。若 P3 结果仍需定位，后续条件比较应优先考虑同一完整状态下 all-minus-E / all-minus-Q 或 E+Q 等必要的少量干预，而不是由单路结果推出必要性/充分性。
5. **从共同初始化的 P3 与局部救援实验分开。** 已保存 100–500 步两臂完整状态，为定位 400→500 变化提供了依据。若在同一 D1@400 完整状态分叉做局部 detach/抑制，必须同时恢复优化器、RNG、loader 和计数器，并保留原 all 延续作配对对照；这只检验当时状态的局部反事实。继续 D0/D1 到 1000/2000 能辨别恢复或持续恶化，不能由后来的恢复抹去 500 步的真实退化。

有限差分的既有边界仍适用：FD8 支持冻结离散状态后的若干局部输出方向检验，batch-3 中尺度 α 不一致尚未完全解释；它不直接验证优化器轨迹、每个参数导数或原生离散切换后的机制。以上 P3 候选不以“全部导数已验证”为前提。
